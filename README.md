# mssamhan31.github.io

Personal website of Samhan Samhan: a static site generated by a small Python package
from a CV spreadsheet, Markdown prose, imported blog posts and a photo gallery. Design and
decisions are in [docs/plan-2026-10-27.md](docs/plan-2026-10-27.md); claims awaiting Samhan's
review are in [docs/review-notes.md](docs/review-notes.md).

## What it does

- Renders Home, About, PhD, CV, Notes, Gallery and Contact from `templates/`
  and `content/`.
- Generates the CV page entirely from `data/cv.json`, a sanitised export of the CV workbook, so
  the site stays complete without hand edits.
- Keeps private data out by construction: `sync_cv.py` drops the references sheet, phone numbers
  and Drive links before anything is committed, and `tests/test_privacy.py` scans every built
  page for what the rules forbid.

## Install and run (Windows, PowerShell)

```powershell
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python build.py                           # writes _site/
python -m http.server 8000 -d _site       # preview at http://localhost:8000
pytest; ruff check .; black --check .
```

## Updating content

| Change | Do this |
|---|---|
| Anything on the CV page | Edit the workbook at the path in `site.yaml` (`cv_source`), run `python sync_cv.py`, read the diff of `data/cv.json`, rebuild. Add a `Web` column with `N` to hide a row. |
| Home, About, PhD, Contact prose | Edit the Markdown in `content/`. Level-2 headings become the side navigation. A line `<!-- projects -->` or `<!-- conferences -->` is replaced by a generated block. |
| Pet-project cards | `content/projects.yaml` |
| Gallery | Put web-sized images in `static/img/gallery/` and list them in `content/gallery.yaml` |
| Blog posts | Save the Blogger page as a complete web page into the source folder named in `import_notes.py`, run `python import_notes.py <part of its file name>`; then set the post's `image` in `content/notes/notes.yaml` |
| Headline, emails, links, nav, organisations linked automatically | `site.yaml` |
| Browser-tab and home-screen icon | `python tools/make_favicon.py <path to a serif .ttf>` redraws the three icon files in `static/` |
| Copy for review in Word | `python tools/make_copy_doc.py` writes `docs/copy-for-samhan.docx` (git-ignored) |

## Data

`data/cv.json` is generated from the workbook `Curriculum Vitae - Complete Data.xlsx` on
Samhan's Google Drive and is the only CV data in the repository. The workbook itself is never
committed (`*.xlsx` is ignored). The notes under `content/notes/` were imported once from saved
Blogger pages; the gallery images are resized copies of photos kept outside the repository.

## Layout

```
build.py            build the site into _site/
sync_cv.py          workbook -> data/cv.json with the privacy filter (local only)
import_notes.py     saved Blogger pages -> content/notes/ (local, one post at a time)
tools/              make_favicon.py (icons), make_copy_doc.py (Word copy for review)
site.yaml           public settings
sitegen/            cv_data (rules), privacy (patterns), images (resizing), render (pages)
templates/          Jinja2 templates and partials
content/            Markdown prose, projects.yaml, gallery.yaml, notes/
static/             css, js, img (copied to the output as-is)
data/cv.json        sanitised CV data
tests/              pytest: data rules, privacy scan, build checks
docs/               plan and review notes
```

## Deployment

Live at https://mssamhan31.github.io/ since 27 October 2026. `.github/workflows/deploy.yml`
builds and publishes the site to GitHub Pages on every push to `main`; the Pages source is set to
GitHub Actions.
